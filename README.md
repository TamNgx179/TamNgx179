**Full-stack Developer · Team of 6**

| Read & ask | Process & retrieve | Protect & deliver |
| --- | --- | --- |

**Built with:** Java · Spring Boot · Next.js · Tailwind CSS · PostgreSQL · MongoDB · Redis · Qdrant · Docker
